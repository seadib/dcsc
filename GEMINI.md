# Project Rules: Dhaka College Science Club (DCSC)

Whenever pushing or uploading code/assets to Git:
1. Always activate and follow the `git-release-manager` skill in `.agents/skills/git-release-manager/SKILL.md`.
2. Ensure every push has a corresponding Semantic Version tag (`vX.Y.Z`).
3. Always include the standardized Live Links format in releases and docs:
   ```markdown
   ### 🔗 Live Links:
   - 🌐 **Live Website**: https://seadib.github.io/dcsc
   - 🛠️ **Admin Dashboard**: https://dcsc.sanity.studio
   - 💻 **Repository**: https://github.com/seadib/dcsc
   ```
4. Automatically publish the official GitHub Release on `https://github.com/seadib/dcsc/releases` with detailed notes and asset verification.
